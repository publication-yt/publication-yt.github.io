Privacy policy

Applies to the application “Publication”. Last updated: 20 November 2026.

Summary

Publication is a private tool used only by its owner to upload their own videos to their own YouTube channels. It does not collect, sell or share any personal data.

Google data the application accesses

  • The application requests a single Google permission: https://www.googleapis.com/auth/youtube.upload, used to upload videos and set their metadata and publication date.
  • It does not read your email, contacts, files, viewing history or any other Google data.

How data is stored

  • The OAuth access token is stored only on the owner's own computer, in a local file. It is never sent to any server other than Google's.
  • No database, analytics, cookies or tracking are used. This website itself sets no cookies.

Sharing

No data is shared with, sold to or transferred to any third party. Data is used only to provide the upload feature described above.

Publication's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

Publication uses YouTube API Services. By using it you are bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google account permissions. Deleting the local token file also removes the application's access.
